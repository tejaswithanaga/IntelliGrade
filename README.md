# IntelliGrade

## Project Overview
IntelliGrade is an assignment management and evaluation system designed to simplify the process of creating, managing, submitting, and evaluating assignments for teachers and students.

## Features
- Teacher and student login
- Role-based access
- Assignment creation and management
- Objective and descriptive questions
- Student assignment submissions
- Assignment evaluation
- Assignment deadline management
- Reopening assignments by extending deadlines

## User Roles
**Teacher**
- Create and manage assignments
- Add questions
- Evaluate student submissions
- Manage assignment deadlines

**Student**
- View available assignments
- Answer assignment questions
- Submit assignments
- View evaluation results
